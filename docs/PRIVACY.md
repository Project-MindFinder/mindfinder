# MindFinder 개인정보 처리방침

MindFinder(이하 "봇")는 폐쇄병동 입원 경험자 커뮤니티를 위한 디스코드 봇으로, 이용자의 민감한 건강 정보를 다룹니다. 본 방침은 어떤 정보를 어떻게 수집·이용·보관·파기하는지 설명합니다.

## 1. 수집하는 정보

| 구분 | 항목 | 목적 |
|---|---|---|
| 필수 | 디스코드 사용자 ID | 계정 식별 |
| 이력 | 입원 병원명, 입원 연·월, 퇴원 연·월 | 매칭 및 커뮤니티 |
| 선택 | 인증 증빙 서류 (입퇴원확인서 등) | 서류 심사 |
| 설정 | 매칭 희망 여부 | 매칭 대상 필터링 |
| 매칭 | 매칭 채널 ID 및 참여자 목록 (디스코드 ID) | 비공개 채널 접근 권한 관리 |
| 기록 | 명령 사용 감사 로그 (행위자 ID, 시각, 동작) | 운영·보안 |

**수집하지 않는 정보**
- 전화번호, 주민등록번호, SNS 계정, 이메일 등
- 봇은 연락처를 저장하거나 전달하지 않습니다.
- 매칭 채널의 **대화 내용은 저장하지 않습니다** (디스코드 서버에만 존재하며 봇은 보관하지 않음).

## 2. 정보의 이용

- 같은 병원·시기 입원자 간 매칭 후보 탐색
- 병원·기간 단위 커뮤니티 운영
- 서류 심사를 통한 인증 배지 부여
- 위기 상황 시 상담 안내 제공

## 3. 매칭과 비공개 채널

- 매칭은 **양쪽 모두 동의한 경우에만** 성사됩니다.
- 성사 시 봇은 당사자들과 봇만 볼 수 있는 **비공개 채널**을 만들고 참여자들을 초대합니다.
- 봇은 채널의 **접근 권한만 관리**하며, 대화 내용이나 추가 개인정보(전화번호/SNS 등)를 저장·전달하지 않습니다.
- 참여자는 `/매칭초대` 로 같은 병원·시기 동료를 채널에 추가할 수 있어, 1:1이 아닌 여러 명이 한 채널을 공유할 수도 있습니다.
- 추가 개인정보 공유 여부와 내용은 전적으로 이용자 본인의 판단과 책임하에 이루어집니다.

## 4. 증빙 서류 보관 및 파기

- 증빙 서류는 **비공개 채널**에만 업로드되며 관리자만 열람합니다.
- 심사(승인/거절) 완료 즉시 봇이 해당 메시지를 **자동 삭제**합니다.
- 별도의 사본을 저장하지 않습니다.

## 5. 보관 기간

- 입원 이력 및 매칭 설정: 이용자가 삭제를 요청할 때까지
- 감사 로그: 운영 및 보안 목적상 일정 기간 보관 후 파기
- 증빙 서류: 심사 완료 즉시 파기 (제5항)

## 6. 정보의 제3자 제공

- 원칙적으로 제3자에게 제공하지 않습니다.
- 매칭 성사 시 상대방에게 공개되는 것은 **디스코드 사용자 멘션(핸들)에 한정**되며, 비공개 채널 참여자에게만 노출됩니다.
- 비공개 채널의 참여자 목록은 해당 채널 참여자와 봇 관리자에 한해 접근할 수 있습니다.

## 7. 보안 조치

- 봇 토큰 등 비밀값은 환경변수(`.env`)로 관리하며 코드/저장소에 포함하지 않습니다.
- 최소 권한 원칙에 따라 봇 인텐트와 역할을 제한합니다.
- 서버(또는 컨테이너) 접근 권한을 제한하고, DB 파일은 정기적으로 백업합니다.
- 관리자(심사자)는 역할 기반으로 접근을 통제합니다.

## 8. 이용자의 권리

- 자신의 입원 이력과 매칭 설정을 조회·수정·삭제할 수 있습니다.
- 개인정보 관련 문의는 서버 관리자에게 요청할 수 있습니다.

## 9. 위기 상황 대응

- 자해·자살 등 위험 표현이 감지되면 상담 핫라인 안내를 제공합니다.
- 이는 이용자의 안전을 위한 최소한의 개입이며, 해당 메시지를 별도로 저장하지 않습니다.

## 10. 방침의 변경

- 본 방침은 필요 시 변경될 수 있으며, 변경 시 서버 공지를 통해 안내합니다.
